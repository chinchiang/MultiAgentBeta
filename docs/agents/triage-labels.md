# Triage labels

工程 skills 的五種分類角色對應以下 GitHub labels。
套用角色時使用此表中的名稱；修改分類詞彙時同步更新本表，
避免建立語意重複的標籤。

| 角色／Label | 意義 |
| --- | --- |
| needs-triage | 等待維護者評估 |
| needs-info | 等待回報者補充資訊 |
| ready-for-agent | 規格完整，可交由 agent 執行 |
| ready-for-human | 需要人類實作 |
| wontfix | 不予處理 |

# Triage labels

Map the five engineering skill roles to these GitHub labels.
Use these names when applying a role. Update this table when
changing vocabulary to avoid duplicate labels.

| Role / Label | Meaning |
| --- | --- |
| needs-triage | Awaiting maintainer evaluation |
| needs-info | Awaiting reporter information |
| ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |
